Malicious URL Detector 🚨
A machine learning-based web security tool that detects and classifies URLs as SAFE, PHISHING, MALWARE, DEFACEMENT, or OTHER.

Classifies URLs into 5 categories:
✅ Safe
⚠️ Phishing
🐛 Malware
🪪 Defacement
❓ Other

 Tech Stack
Python
LightGBM (Machine Learning Model)
Pandas, NumPy, Scikit-learn (Data Processing)
